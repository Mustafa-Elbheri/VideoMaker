# مكتبة المؤثرات المجانية

هذه حزمة بداية مجانية تم تحميلها من Mixkit.

المصدر:

- https://mixkit.co/free-sound-effects/whoosh/
- https://mixkit.co/free-sound-effects/impact/
- https://mixkit.co/free-sound-effects/notification/
- https://mixkit.co/free-sound-effects/click/
- https://mixkit.co/free-sound-effects/applause/
- https://mixkit.co/free-sound-effects/pop/
- https://mixkit.co/free-stock-video/transition/
- https://mixkit.co/free-stock-video/countdown/

الرخصة:

- https://mixkit.co/license/

محتوى الحزمة:

- 12 مؤثر صوتي بصيغة MP3.
- 6 مؤثرات فيديو بصيغة MP4.
- ملف `manifest.json` يحتوي على الاسم العربي والوصف والمدة والمصدر لكل مؤثر.
- 30 مؤثر صوت وصورة بصيغة MP4 داخل `audio_video`.
- ملف `accessible_manifest.json` يحتوي على المؤثرات المناسبة للمكفوفين، وكلها بدون موسيقى.
