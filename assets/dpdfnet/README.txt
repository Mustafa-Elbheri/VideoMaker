DPDFNet 48 kHz speech enhancement runtime

Bundled model:
dpdfnet2_48khz_hr.onnx

Source:
https://github.com/ceva-ip/DPDFNet

The application uses this model for the Arabic "تنقية الصوت الاحترافية"
effect. The public UI intentionally uses a clear Arabic effect name, while the
model name remains an internal technical dependency.
