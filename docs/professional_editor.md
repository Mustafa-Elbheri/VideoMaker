# المحرر الاحترافي (DAW)

يُفعَّل المحرر الاحترافي من الإعدادات أو بمفتاح `Shift+.` للتبديل بين الوضع العادي والاحترافي.
كل سلوك المحرر الاحترافي يعمل خلف شرط الوضع الاحترافي فقط، ولا يلمس الوضع العادي نهائياً.

## التراكات الخمسة

| التراك | المفتاح | يقبل |
|---|---|---|
| المقطع الرئيسي | `main_video` | فيديو فقط |
| المقطع الثانوي | `secondary_video` | فيديو وصور |
| المؤثرات الصوتية | `sound_effects` | صوت فقط |
| الخلفية الصوتية | `background_audio` | صوت فقط |
| النصوص | `text` | نصوص ديناميكية قابلة للتعديل |

التنقل بين التراكات: `سهم لأعلى` / `سهم لأسفل`. كل تراك مستقل بترتيب عناصره، والبرنامج يتحقق من نوع
المحتوى عند الإدراج.

## اختصارات المحرر الاحترافي

| مفتاح | الوظيفة | الاحترافي فقط؟ |
|---|---|---|
| `I` | إدراج عند المؤشر (بالطول الطبيعي حسب نوع التراك) | نعم |
| `S` | قص العنصر عند المؤشر على التراك الحالي | نعم |
| `Delete` | حذف العنصر المركّز/المحدد | نعم |
| `Ctrl+يمين/يسار` | تنقل بين عناصر التراك الحالي | نعم |
| `Ctrl+Shift+يمين/يسار` | تحديد متعدد تراكمي | نعم |
| `Ctrl+A` | تحديد الخط الزمني كامل بكل عناصره | نعم |
| `Ctrl+X/C/V` | قص/نسخ/لصق عناصر | نعم |
| `Ctrl+M` | كتم التراك الحالي أو رفع الكتم عنه | نعم |
| `Alt+P` | تبديل وضع Ripple بين الأوضاع الثلاثة | نعم |
| `Ctrl+E` | تعديل العنصر النصي المركّز | نعم |
| `Numpad 4` | إزاحة العنصر المركّز يساراً بمقدار خطوة التنقل | نعم |
| `Numpad 6` | إزاحة العنصر المركّز يميناً بمقدار خطوة التنقل | نعم |
| `Numpad 8` | نقل العنصر المركّز إلى التراك السابق | نعم |
| `Numpad 2` | نقل العنصر المركّز إلى التراك التالي | نعم |

## أوضاع Ripple الثلاثة

| الوضع | السلوك |
|---|---|
| `per_track` (لكل تراك) | عند القص أو الحذف أو الإدراج يتحرك فقط ما بعد العملية على التراك نفسه |
| `all_tracks` (كل التراكات) | تتحرك العناصر بعد العملية على كل التراكات معاً |
| `off` (مطفأ) | تبقى كل العناصر في أماكنها وتُترك فجوات |

مثال: قص أو حذف عنصر وسط ثلاثة أجزاء في وضع `all_tracks` يلحم الطرفين على كل التراكات.

## التحديد المتعدد والحافظة

- `Ctrl+يمين/يسار` يحرك التركيز بين عناصر التراك الحالي فقط.
- `Ctrl+Shift+يمين/يسار` يوسّع التحديد التراكمي.
- `Ctrl+X/C/V` تعمل على العناصر المحددة عبر التراكات، واللصق يتم في التراك الحالي عند المؤشر مع
  تحريك العناصر حسب وضع Ripple.
- `Ctrl+Z` / `Ctrl+Y` للتراجع والإعادة عبر كل الحالة الاحترافية (الكتم، Ripple، التحديدات، النصوص، المؤثرات).

## الحفظ والاسترجاع

- الحفظ (`Ctrl+S`) والجلسات (`Ctrl+J`، `Ctrl+Shift+J`، `Ctrl+Alt+J`) والمشاريع تحفظ وتستعيد:
  حالة كتم التراكات، وضع Ripple، العنصر المركّز، التحديدات، العناصر الصوتية والنصوص الديناميكية.
- المشاريع القديمة (مخطط 1) تُفتح تلقائياً دون تحويل إجباري.

## المعاينة والتصدير

- التراكات الصوتية الثلاثة (المؤثرات، الخلفية، الصوت الأصلي) تُخلط في المعاينة والتصدير.
- التراكات المكتومة تُستبعد نهائياً من المعاينة والتصدير.
- النصوص الديناميكية تُدمج في التصدير فوق الفيديو.
